## 💼 Опыт работы

### 🟡 Yandex Crowd — Middle+ Backend Developer
`Февраль 2024 — настоящее время`

Спроектировал и запустил платформу из **13+ микросервисов** (подразделение 300+ человек). Экономит **750+ чел/ч в год** времени тимлидов, аналитиков и наставников.

| Сервис | Нагрузка | Стек | Что сделано |
|--------|----------|------|-------------|
| **Data Collector** | 2400 RPS | Python · FastAPI · ClickHouse | Асинхронный прокси с батчингом и пулом соединений. **0% ошибок** |
| **RBAC Service** | 5500 RPS | Java · Spring · PostgreSQL | Централизованное управление доступом |
| **Site Proxy** | 4500 RPS | Go · net/http · PostgreSQL | Агрегация инфраструктуры, выдача статики, аутентификация |
| **GlitchGen** | — | Python · PostgreSQL · asyncio | Заменил синхронный SDK на асинхронный → пропускная способность **×5+** |
| **Ragnarok** | — | Python · gRPC · asyncio | Асинхронная надстройка над gRPC Yandex Cloud → очистка **×4 быстрее** |

**Архитектура и инфраструктура**
- 🏗 Заложил архитектурный фундамент: ретраи, авто-восстановление, синхронное (REST) и асинхронное (Kafka) взаимодействие, независимое горизонтальное масштабирование
- 🔐 Внедрил **Zero Trust**: mTLS между сервисами, TLS к БД, bastion-хост с 2FA, OAuth2 + JWT, RBAC, LockBox для секретов
- ⚙️ Автоматизировал **CI/CD на GitHub Actions**: тесты на каждый PR в main, релиз фичи — **2 минуты** с момента мержа, SLA **99.9%** по метрикам Prometheus
- 📦 Написал библиотеку для Monium с авто-ротацией IAM-токенов и API-ключей и кэшированием

**Команда и процессы**
- 👥 Менторство: код-ревью для 4 разработчиков, онбординг, участие в найме и exit-интервью
- 📚 Выстроил документационную базу: карта документации, карта ответственных, единые шаблоны и чек-листы
